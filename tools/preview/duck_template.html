Rubber duck mode

With the setting on, every 2 in the hours and minutes becomes a rubber duck. Each duck sits in exactly the 2's own box, so the time never gets wider and the week number still clears the side panel. Every duck is built from a few circles and polygons drawn in code, with no images, so it costs almost no memory.

Round three. The neck is gone or thin, the head is round again, and the body is taller. The duck is still exactly the digit height and the 2's width. Pick option A or B. The original design 3 is below for comparison.
